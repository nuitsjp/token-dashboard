# 保存失敗や離脱時に下書きを保護する

- 種別: 拡張
- UI確認: 要

## 分岐条件

保存時に入力不正や保存失敗が発生する、または未保存状態から画面遷移や終了を行う。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 保存を指示し、入力不正または保存失敗となる | 下書きを保持して原因を表示する |
| 2 | 未保存のまま画面遷移または終了を指示する | 確認を求める |
| 3 | 確認を取り消す | 下書きを維持する。保存処理中は破棄して移動しない |

## 受け入れ条件

入力不正や保存失敗時、および画面遷移や終了の取り消し時に下書きを維持すること。保存処理中に下書きを破棄して移動しないこと。
