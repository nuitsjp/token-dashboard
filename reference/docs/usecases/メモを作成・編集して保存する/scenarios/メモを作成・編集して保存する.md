# メモを作成・編集して保存する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者がメモを新規作成または編集する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 新規作成または一覧からメモを選択する | 保存済み内容を表示する |
| 2 | タイトル・本文を編集し、保存を指示する | Go が入力を検証し、一体で保存する。保存結果と更新された一覧を表示する |

## 受け入れ条件

再読み込み・再起動後も保存内容を取得できること。同一 ID の編集で件数が増加しないこと。保存結果の表示は、再編集・画面遷移・履歴の移動の後に再表示しないこと。
