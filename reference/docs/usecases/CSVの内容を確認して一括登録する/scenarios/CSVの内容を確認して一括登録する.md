# CSVの内容を確認して一括登録する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者が CSV から複数のメモをまとめて追加する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | CSV を入力する | 既存件数を表示する |
| 2 | 確認を指示する | Go が CSV を解析し、登録候補を確認画面に表示する |
| 3 | 候補を確認し、必要なら入力画面へ戻る | 入力画面へ戻っても CSV を保持する |
| 4 | 実行を指示する | Go が同じ CSV を再検証し、進捗を通知しながら全件を一括保存する。確定件数を表示し、一覧を再取得する |

中止要求と確定が重なる場合は保存結果を断定せず、一覧で実状態を確認します。UI 上の中止要求と Go での中止完了を区別します。

## 受け入れ条件

プレビュー段階では保存しないこと。全件検証が成功した場合のみ追加し、途中失敗や中止時は一部のみ追加しないこと。演出目的の待機時間を設けず、件数が少ない場合は進捗表示が瞬時に終わってよいこと。
