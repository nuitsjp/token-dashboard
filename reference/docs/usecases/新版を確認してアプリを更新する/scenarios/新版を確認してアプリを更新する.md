# 新版を確認してアプリを更新する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者がアプリの更新を確認する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 更新確認を指示する | Go が配布元の署名済み更新情報を検証し、新版があれば表示する |
| 2 | 取得を指示する | Go がインストーラーをローカルへ取得し、署名されたサイズとハッシュの一致を検証する |
| 3 | 適用を確認する | Go が稼働処理を確認して取得物を再検証し、NSIS を起動する。アプリが終了し、NSIS が旧プロセスの終了を待って適用後に新版を起動する |

## 受け入れ条件

対象アプリ・CPU・版・署名・ハッシュが不正なファイルを実行しないこと。取得や検証、起動の失敗でアプリを終了しないこと。保存データを削除しないこと。実際の適用成功前に「更新完了」と表示しないこと。
