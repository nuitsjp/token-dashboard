# 利用状況の取得元と表示先を設定する

## 主アクター
利用者

## 目的
利用状況の取得元と表示先の TURZX を選び、アプリを再起動してもその設定で表示できるようにする。

## 前提
アプリが起動し、タスクトレイに常駐している。

## 共通の受け入れ条件
- 取得元は `Local` と `Hub` から選ぶ。取得元の保存値がなければ `Local` を使用する。
- `Local` の利用に、利用者による tokscale の別途インストールを要求しない。
- Hub の認証トークンは画面・ログに表示せず、本体から画面へ返さない。Hub の URL と認証トークンを保存する場合は、一組にして Windows の DPAPI でユーザー単位に暗号化する。
- 選択した取得元で取得に失敗しても、別の取得元へ自動では切り替えない。
- 画面の見出しと項目名は英語で表示する。
