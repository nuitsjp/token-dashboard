# 利用状況の取得元と表示先を設定する

## 主アクター
利用者

## 目的
利用状況の取得元と表示先の TURZX を選び、アプリを再起動してもその設定で表示できるようにする。

## 前提
アプリが起動し、タスクトレイに常駐している。

## 共通の受け入れ条件
- 取得元は `Local` と `Hub` から選ぶ。取得元の保存値がなければ `Local` を使用する。
- `Local` の利用に、利用者による tokscale の別途インストールを要求しない。
- Hub の認証トークンは画面・ログに表示せず、本体から画面へ返さない。Hub の URL と認証トークンを保存する場合は、一組にして Windows の DPAPI でユーザー単位に暗号化する。
- 選択した取得元で取得に失敗しても、別の取得元へ自動では切り替えない。
- 画面の見出しと項目名は英語で表示する。
- ウィンドウは左の縦メニューで `Display` 画面と `Connection` 画面を切り替える。`Display` 画面には表示プレビューと出力先 `Output device`、`Connection` 画面には取得元 `Data source` と Hub の接続先を置く。
- `Save` は画面ごとに置き、その画面の項目だけを保存する。`Display` 画面の `Save` は表示先、`Connection` 画面の `Save` は取得元・Hub の URL・認証トークンを保存する。
- 入力は画面を切り替えても保持する。保存していない他画面の入力は、`Save` を押しても保存しない。
- 更新の区画は、どちらの画面でも先頭に表示する。
