# ローカルを取得元にして表示先を保存する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者がタスクトレイのアイコンからウィンドウを開く。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者がタスクトレイのアイコンをクリックする | ウィンドウを表示する。設定区画に取得元 `Local`・`Hub` と現在の選択、表示先 `Automatic` と接続中の TURZX を表示する。取得元の保存値がなければ `Local` を選択状態にする |
| 2 | 利用者が `Local` と表示先を選ぶ | 選択を画面上に保持する。この時点では保存しない |
| 3 | 利用者が `Save` を押す | 取得元と表示先を保存し、実行中の取得処理をローカル取得へ切り替える。保存完了を示す |
| 4 | 利用者がアプリを終了して再起動し、ウィンドウを開く | `Local` と手順3で保存した表示先を選択状態で表示する |

## 受け入れ条件

- `Local` の保存時には Hub の URL と認証トークンを要求しない。
- 保存後と再起動後に、ローカル取得が選択された状態で動作する。
- `Automatic` では、接続中の TURZX を識別子順の先頭から選ぶ。特定の機器を選んだ場合、その機器が未接続でも選択を保持し、ほかの機器へ自動では切り替えない。
- 表示先の選択肢には、製品名とシリアル番号の先頭8文字を `TURZX1.0 (633A6E01)` の形式で表示する。
