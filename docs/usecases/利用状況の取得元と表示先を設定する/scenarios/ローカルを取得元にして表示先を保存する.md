# ローカルを取得元にして表示先を保存する

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者がタスクトレイのアイコンからウィンドウを開く。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者がタスクトレイのアイコンをクリックする | ウィンドウを表示する。左の縦メニューに `Display` と `Connection` を表示し、`Display` 画面を開く。`Display` 画面に表示プレビューと表示先 `Automatic` と接続中の TURZX を表示する |
| 2 | 利用者が `Connection` 画面を開き、取得元 `Local` を選んで `Save` を押す | 取得元の保存値がなければ `Local` を選択状態で表示している。取得元を保存し、実行中の取得処理をローカル取得へ切り替える。保存完了を示す |
| 3 | 利用者が `Display` 画面を開き、表示先を選ぶ | 表示先を直ちに保存し、次の画像から新しい表示先へ送る |
| 4 | 利用者がアプリを終了して再起動し、ウィンドウを開く | `Connection` 画面に `Local`、`Display` 画面に手順3で保存した表示先を選択状態で表示する |

## 受け入れ条件

- `Local` の保存時には Hub の URL と認証トークンを要求しない。
- 保存後と再起動後に、ローカル取得が選択された状態で動作する。
- `Automatic` では、接続中の TURZX を識別子順の先頭から選ぶ。特定の機器を選んだ場合、その機器が未接続でも選択を保持し、ほかの機器へ自動では切り替えない。
- 表示先の選択肢には、製品名とシリアル番号の先頭8文字を `TURZX1.0 (633A6E01)` の形式で表示する。
