# Hubを取得元にして接続先と表示先を保存する

- 種別: 拡張
- UI確認: 要

## 分岐条件
設定画面で利用者が取得元に `Hub` を選ぶ。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が `Hub` を選ぶ | Hub の URL 入力欄、認証トークンの入力欄と設定状態（`Not set` または `Set`）を表示する。保存済みの URL は表示し、認証トークンの入力欄は空にする |
| 2 | 利用者が URL と認証トークンを入力し、表示先を選ぶ | 入力と選択を画面上に保持する。この時点では保存しない |
| 3 | 利用者が `Save` を押す | 入力を検証し、取得元、暗号化した URL と認証トークン、表示先を保存する。Hub 受信へ切り替え、保存完了を示し、トークン入力欄を空に戻す |
| 4 | 利用者がアプリを終了して再起動し、ウィンドウを開く | `Hub`、保存した URL と表示先、トークンの設定状態 `Set` を表示する |

## 受け入れ条件
- URL は `http(s)://ホスト[:ポート]` の形式だけを受け付ける。
- トークン入力欄を空にして保存した場合、保存済みのトークンを使う。保存済みのトークンもない場合は保存しない。
- 保存ファイルには URL と認証トークンの平文を含めない。
- 表示先の選択と未接続時の扱いは、主成功シナリオと同じにする。
