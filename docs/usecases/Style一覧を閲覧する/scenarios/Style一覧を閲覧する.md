# Style一覧を閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件
最新の利用状況を1回以上受信している。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が左メニューの `Styles` を開く | 見出し `Styles` を表示する。その時点の定義ごとにカードを作る。組み込みは `Gauges`、`Bars` の順で先に並べ、それ以外は `name` の昇順（同じ `name` は `id` の昇順）で続ける。カードには `name` と、そのスタイルで描いた現在の表示画像を、縦横比 1920:462 のまま幅に合わせて表示する。組み込みのカードに `Built-in` を表示する。現在の表示に使っているスタイル（設定に値がなければ `Gauges`）のカードに `In use` を表示する |
| 2 | 取得元の利用状況が更新される、または1分が経過する | 各カードのプレビューを、同じスタイルのまま描き直す。カードの並び、`Built-in`、`In use` は変えない |
| 3 | 表示スタイルの定義が追加または削除される | 一覧を、その時点の定義に合わせて作り直す。組み込みの `Gauges` と `Bars` のカードは残し、`Built-in` を表示したままにする |

## 受け入れ条件
- カードは、その時点の表示スタイル定義と一対一で一致する。名称は定義の `name` と一致する。`id` が異なる定義は、`name` が同じでも別のカードにする。
- `Gauges` と `Bars` のカードは常にあり、`Built-in` を表示する。組み込み以外の定義は、あるときだけカードにする。
- カードに選択操作を置かない。
- 各プレビューは、そのスタイルで描いた表示画像である。TURZX へ送る画像は、現在の表示に使っているスタイルのままとする。
