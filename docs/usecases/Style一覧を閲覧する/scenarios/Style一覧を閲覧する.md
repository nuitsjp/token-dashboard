# Style一覧を閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件
最新の利用状況を1回以上受信している。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が左メニューのStylesを開く | その時点の定義ごとにカードを表示する。Gauges、Bars、残りの組み込み、追加スタイルの順とし、後二者はそれぞれ名前・IDの昇順に並べる。名前と各スタイルの縦横比に合うプレビューを表示する。組み込みにBuilt-in、選択中にIn useを表示する |
| 2 | 取得元の利用状況が更新される、または1分が経過する | 各カードを同じスタイルで描き直す。カードの並びと表示中スタイルの選択は変えない |
| 3 | 定義が追加または削除される | 確定した定義に合わせて一覧を更新する。組み込み6スタイルを維持する |

## 受け入れ条件
- カードは定義と一対一で対応し、名前は定義と一致する。同名でもIDが異なれば別カードとする。
- Outputで候補を絞らず、両機種の全スタイルを比較できる。
- カードにスタイルの選択操作を置かない。
- プレビューの生成は、実機表示のページと巡回期限を変更しない。
- 表示先、取得元、保存設定を変更せず、実機とDisplayのプレビューは選択中スタイルのまま更新する。
