# Style一覧を閲覧する

## 主アクター
利用者

## 目的
アプリに定義された表示スタイルを一覧で見て、現在の表示を変えずに見比べる。

## 前提
- アプリが起動し、タスクトレイに常駐している。
- 表示スタイルの定義の集合は変わりうる。一覧は、その時点の集合から作る。
- `Gauges`（`id` は `gauges`）と `Bars`（`id` は `bars`）は組み込みの定義であり、常に集合に含まれる。
- 組み込み以外の定義は、追加されていれば集合に含まれ、削除されていれば含まれない。

## 共通の受け入れ条件
- 画面の見出しと項目名は英語で表示する。
- 更新の区画は、この画面でも先頭に表示する。
- 一覧を開いても、取得元・Hub の接続設定・表示先・表示スタイル・表示しない利用枠は変わらない。TURZX と `Display` 画面のプレビューは、現在の表示に使っているスタイルのまま更新する。
