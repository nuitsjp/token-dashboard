# Styleを削除する

## 主アクター
テーマ作者

## 目的
追加した表示スタイルを1つアプリの定義から取り除く。

## 前提
- アプリが起動している。
- 組み込み6スタイルは削除できない。
- 対象は取り込んだ組み込み以外のスタイルである。
- 追加元のフォルダーではなく、Styles画面から操作する。

## 共通の受け入れ条件
- 画面の見出し、ボタン、エラーは英語で表示する。
