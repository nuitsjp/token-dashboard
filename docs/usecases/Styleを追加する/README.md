# Styleを追加する

## 主アクター
テーマ作者

## 目的
組み込み以外の表示スタイルをアプリの定義に加え、対応する表示先で使用する。

## 前提
- アプリが起動している。
- アプリには9.2インチ用のGauges・Barsと、3.5インチ用の横・縦のGauges・Barsが組み込まれている。
- テーマ作者は追加元のフォルダーを指定する。アプリ内部の定義置き場へ、自分ではファイルを置かない。

## 共通の受け入れ条件
- 画面の見出し、ボタン、エラーは英語で表示する。
- 表示対象、ページ分割、巡回、焼き付き対策は、選択した表示データ構成に対応する[表示ユースケース](../利用状況をUSBディスプレイに表示する/README.md)と[焼き付き防止ユースケース](../USBディスプレイの焼き付きを防ぐ/README.md)のシナリオに従う。
