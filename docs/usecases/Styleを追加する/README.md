# Styleを追加する

## 主アクター
テーマ作者

## 目的
組み込み以外の表示スタイルを1つアプリの定義に加える。

## 前提
- アプリが起動している。
- アプリには組み込みの `Gauges`（`id` は `gauges`）と `Bars`（`id` は `bars`）がある。
- テーマ作者は追加元のフォルダーを指定する。アプリ内部の定義置き場へ、自分ではファイルを置かない。

## 共通の受け入れ条件
- 画面の見出し、ボタン、エラーは英語で表示する。
