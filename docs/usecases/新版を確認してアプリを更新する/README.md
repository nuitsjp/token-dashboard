# 新版を確認してアプリを更新する

## 主アクター
利用者

## 目的
起動のたびに GitHub Releases の新版をバックグラウンドで確認して取得・検証しておき、利用者が選んだときだけ新版に更新して再起動する。

## 前提
- アプリはインストーラーで導入されている。
- GitHub Releases の最新リリース（下書きとプレリリースを除く）に、署名した `update.json` とインストーラーが置かれている。

## 共通の受け入れ条件
- 新版の確認・取得・検証は、Hub の受信、TURZX への表示、タスクトレイとウィンドウの操作を止めない。
- `update.json` の署名、対象アプリと CPU、インストーラーのサイズとハッシュのどれかが一致しない新版は、取得済みとして扱わない。
- 画面とタスクトレイのメニューの文言は英語で表示する。
