# Hubの接続設定を登録・変更する

## 主アクター
利用者

## 目的
受信する Hub の接続先 URL と認証トークン、表示先の TURZX を設定し、アプリを終了・再起動しても同じ設定で動くようにする。

## 前提
アプリが起動し、タスクトレイに常駐している。

## 共通の受け入れ条件
- 認証トークンは画面に表示しない。本体から画面へも返さず、ログにも出さない。
- 接続先 URL と認証トークンは1組にまとめ、Windows の DPAPI でユーザー単位に暗号化して保存する。どちらも平文ではディスクに書かない。
- 画面の見出しと項目名は英語で表示する。
