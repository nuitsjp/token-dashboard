# 接続先と表示先を入力して保存する

- 種別: 主成功
- UI確認: 要

## 開始条件
利用者がタスクトレイのアイコンからウィンドウを開く。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者がタスクトレイのアイコンをクリックする | ウィンドウを表示する。設定区画には、保存済みの接続先 URL、認証トークンの設定状態（`Not set` または `Set`）、表示先の選択肢と現在の選択を表示する。表示先の選択肢は `Automatic` と、接続中の TURZX の一覧。認証トークンの入力欄は空にしておく |
| 2 | 利用者が接続先 URL と認証トークンを入力し、表示先を選ぶ | 入力と選択を画面上に保持する。この時点では保存しない |
| 3 | 利用者が `Save` を押す | 入力を検証し、接続先 URL と認証トークンを1組で暗号化して保存する。表示先の選択も保存する。保存が済んだことを示し、認証トークンの入力欄を空に戻して、設定状態を `Set` にする |
| 4 | 利用者がタスクトレイのメニューの `Exit` でアプリを終了し、再び起動してウィンドウを開く | 手順3で保存した接続先 URL と表示先の選択を表示し、認証トークンの設定状態を `Set` と表示する |

## 受け入れ条件
- 保存後に再起動しても、保存した接続先 URL、表示先の選択、認証トークンの設定状態 `Set` が表示される。
- 保存したファイルに、接続先 URL と認証トークンの平文が含まれない。
- 認証トークンの入力欄が空のまま `Save` を押した場合は、保存済みの認証トークンをそのまま使う。
- 接続先 URL は `http(s)://ホスト[:ポート]` の形式だけを受け付ける。
- 表示先が `Automatic` のときは、接続中の TURZX を機器の識別子で並べた先頭の1台を表示先にする。表示先に選んだ機器が接続されていないときは、その機器を選択肢に `(Disconnected)` を付けて残し、ほかの機器へ自動では切り替えない。
- 表示先の各選択肢には、機器が USB で名乗る製品名（例: `TURZX1.0`）と、識別子の末尾にあるシリアル番号の先頭8文字を、`TURZX1.0 (633A6E01)` の形式で表示する。
