# 設定を編集する

## 主アクター
利用者

## 目的
表示の切り替えや離席の判定など、使い方に関わる設定を、表示の画面から切り離した設定画面で編集して保存する。

## 前提
- アプリが起動し、タスクトレイに常駐している。

## 共通の受け入れ条件
- 画面の見出しと項目名は英語で表示する。
- ウィンドウは左の縦メニューで `Display` 画面、`Styles` 画面、`Connection` 画面、`Settings` 画面を切り替える。`Settings` は縦メニューの最後に置く。
- `Settings` 画面の項目は `Save` なしで、操作した時点で反映して保存する。保存に成功したときは完了の表示を出さない。保存に失敗した場合は、入力を保存前の値に戻し、エラーを表示する。
- この画面の保存は、取得元・接続設定・表示先・表示スタイル・枠の選択の保存値と取得処理に影響しない。
- `Cycle` / `Cycle time` と `Away time` の保存形式・範囲・既定値・動作は、それぞれ元のシナリオに従い、この画面で変えない。
