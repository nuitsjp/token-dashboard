# 設定を編集する

## 主アクター
利用者

## 目的
9.2インチの表示の切り替えや、機種共通の離席の判定を、Settings画面で編集して保存する。

## 前提
- アプリが起動し、タスクトレイに常駐している。

## 共通の受け入れ条件
- 画面の見出しと項目名は英語で表示する。
- ウィンドウは左の縦メニューで `Display` 画面、`Styles` 画面、`Connection` 画面、`Settings` 画面を切り替える。`Settings` は縦メニューの最後に置く。
- `Settings` 画面の項目は `Save` なしで、操作した時点で反映して保存する。保存に成功したときは完了の表示を出さない。保存に失敗した場合は、入力を保存前の値に戻し、エラーを表示する。
- この画面の保存は、取得元・接続設定・表示先・表示スタイル・枠の選択の保存値と取得処理に影響しない。
- 9.2インチ用の巡回設定と、3.5インチ用の巡回設定は独立させる。3.5インチ用の設定操作は[対象シナリオ](../利用状況をUSBディスプレイに表示する/scenarios/3.5インチでサービスごとの利用枠を順番に表示する.md)に従う。
- `Cycle`・`Cycle time`と`Away time`の保存形式・範囲・既定値・動作は、それぞれ対象シナリオに従う。
