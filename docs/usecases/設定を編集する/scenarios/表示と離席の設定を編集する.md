# 表示と離席の設定を編集する

- 種別: 主成功
- UI確認: 要

## 開始条件
アプリが起動し、ウィンドウを開いている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が縦メニューの `Settings` を選ぶ | `Settings` 画面を表示する。上から、`Display` の区画に切り替えのスイッチ `Cycle` とその右に切り替え時間 `Cycle time`(秒)、`Away` の区画に離席と判定する無操作時間 `Away time`(分)を表示する。保存済みの値を反映し、保存値がなければ `Cycle` は切、`Cycle time` は10秒、`Away time` は10分にする。 |
| 2 | 利用者が `Cycle` を入れるか切る | 直ちに保存し、表示画像を生成し直して TURZX とプレビューを更新する(動作は [表示しきれない利用枠を順番に切り替えて表示する](../../利用状況をUSBディスプレイに表示する/scenarios/表示しきれない利用枠を順番に切り替えて表示する.md) に従う)。 |
| 3 | 利用者が `Cycle time` に秒数を入力して Enter を押すか、入力欄から離れる | 5〜3600の整数なら直ちに保存し、以後の切り替え間隔にする。それ以外は保存せず、入力欄を保存済みの値に戻す。 |
| 4 | 利用者が `Away time` に分数を入力して Enter を押すか、入力欄から離れる | 1〜240の整数なら直ちに保存し、以後の離席の判定に使う。それ以外は保存せず、入力欄を保存済みの値に戻す(動作は [席を離れている間は消灯する](../../USBディスプレイの焼き付きを防ぐ/scenarios/席を離れている間は消灯する.md) に従う)。 |
| 5 | 利用者が他の画面を開いてから `Settings` に戻る、またはアプリを再起動してウィンドウを開く | 保存した値を表示する。 |

## 受け入れ条件
- `Cycle`・`Cycle time`・`Away time` は `Settings` 画面だけに置き、`Display` 画面からは取り除く。
- `Display` 画面の `Style` の区画には `Display style` の選択とプレビューだけを置く。
- スイッチと入力欄のデザインは、移す前と同じにする。
- 保存に失敗した場合は、保存前の値に戻し、エラーを表示し、表示画像も離席の判定も変えない。
- 同じ内容を `Display` 画面と `Settings` 画面の両方には置かない。
