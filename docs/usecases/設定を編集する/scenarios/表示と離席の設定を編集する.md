# 表示と離席の設定を編集する

- 種別: 主成功
- UI確認: 要

## 開始条件
アプリが起動し、ウィンドウを開いている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が縦メニューの`Settings`を選ぶ | `Settings`画面に2つのBoxを表示する。`9.2-inch only`を見出しにしたBoxに、スイッチ`Cycle`と切り替え間隔`Cycle time`（秒）を表示する。`All displays`を見出しにしたBoxに、機種共通の`Away time`（分）を表示する。保存済みの値を反映し、未設定ならCycleはOFF、Cycle timeは10秒、Away timeは10分にする。 |
| 2 | 利用者が`Cycle`を入れるか切る | 直ちに保存する。9.2インチ用スタイルの選択中は、[対象シナリオ](../../利用状況をUSBディスプレイに表示する/scenarios/表示しきれない利用枠を順番に切り替えて表示する.md)に従ってTURZXとプレビューを更新する。3.5インチ用スタイルの選択中は、その巡回に影響させない。 |
| 3 | 利用者が`Cycle time`に秒数を入力してEnterを押すか、入力欄から離れる | 5〜3600の整数なら直ちに保存し、9.2インチ用の切り替え間隔にする。それ以外は保存せず、入力欄を保存済みの値に戻す。 |
| 4 | 利用者が`Away time`に分数を入力してEnterを押すか、入力欄から離れる | 1〜240の整数なら直ちに保存し、機種共通の離席の判定に使う。それ以外は保存せず、入力欄を保存済みの値に戻す。離席時の動作は[対象シナリオ](../../USBディスプレイの焼き付きを防ぐ/scenarios/席を離れている間は消灯する.md)に従う。 |
| 5 | 利用者が他の画面を開いてから`Settings`に戻る、またはアプリを再起動してウィンドウを開く | 保存した値を表示する。 |

## 受け入れ条件
- `Cycle`と`Cycle time`は9.2インチ用の設定とし、選択中のスタイルにかかわらずSettingsに表示する。
- `9.2-inch only`と`All displays`は、それぞれのBox内に見出しとして表示し、適用範囲を明確に分ける。`Display`と`Away`の見出しは重ねて置かない。
- `Cycle`と`Cycle time`は`9.2-inch only`のBox、`Away time`は`All displays`のBoxに置く。
- SettingsのCycleとCycle timeを変更しても、3.5インチ用の間隔、現在ページ、巡回期限を変更しない。
- 3.5インチ用の間隔を変更しても、SettingsのCycleとCycle timeを変更しない。
- スイッチと数値入力欄は既存のデザインを使う。
- 保存に失敗した場合は、保存前の値に戻し、エラーを表示し、表示画像・巡回状態・離席の判定を変更しない。
- 保存中は重複した保存操作を受け付けない。
- キーボードで操作でき、狭い画面でも入力欄や説明が横にはみ出さない。
- 9.2インチ用の巡回設定はSettings、3.5インチ用の巡回間隔はDisplayに置き、同じ設定の編集欄を両画面に重複させない。
