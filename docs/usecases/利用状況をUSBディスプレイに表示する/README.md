# 利用状況をUSBディスプレイに表示する

## 主アクター
利用者

## 目的
Hub が報告する最新のトークン数・推定コストと利用枠の残量を、TURZX とウィンドウのプレビューに常時表示し、作業中に横目で確認できるようにする。

## 前提
- Hub の接続先 URL と認証トークンが保存済みである。
- 表示先の TURZX が WinUSB ドライバー設定済みで接続され、メーカーのソフトは終了している。

## 共通の受け入れ条件
- TURZX とプレビューには、本体が生成した同じ表示画像を表示する。
- 受信した利用状況はメモリにだけ持ち、ファイルに保存しない。
- 認証トークンは画面にもログにも出さない。
- 表示画像の見出しと項目名は英語で表示する。
