# 利用状況をUSBディスプレイに表示する

## 主アクター
利用者

## 目的
選択した取得元（ローカルまたは Hub）の最新のトークン数・推定コストと利用枠の残量を、TURZX とウィンドウのプレビューに常時表示し、作業中に横目で確認できるようにする。

## 前提
- 取得元が `Local` または `Hub` に決まっている。保存値がない場合は `Local` を使う。
- 取得元が `Hub` の場合は、Hub の接続先 URL と認証トークンが保存済みである。
- 表示先の TURZX が WinUSB ドライバー設定済みで接続され、メーカーのソフトは終了している。

## 共通の受け入れ条件
- TURZX とプレビューには、本体が生成した同じ表示画像を表示する。
- 取得・受信した利用状況はメモリにだけ持ち、ファイルに保存しない。
- 認証トークンは画面にもログにも出さない。
- 表示画像の見出しと項目名は英語で表示する。
- 利用枠は、保存された表示スタイル `Display style`（`Gauges` または `Bars`）で描く。保存値がなければ `Gauges` とする。`Gauges` では、上端に Tokens を横に並べ、その下に利用枠を7列の格子に並べる。`Bars` では、左端の列に Tokens を縦に並べ、その右に利用枠を並べる。表示する契約の選び方と並び順、利用枠の色の規則は、どちらのスタイルでも同じにする。
