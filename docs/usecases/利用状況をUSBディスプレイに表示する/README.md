# 利用状況をUSBディスプレイに表示する

## 主アクター
利用者

## 目的
選択した取得元の最新のトークン数、推定コスト、利用枠の残量を、TURZXとウィンドウのプレビューに常時表示し、作業中に確認できるようにする。

## 前提
- 取得元が `Local` または `Hub` に決まっている。保存値がない場合は `Local` を使う。
- 取得元が `Hub` の場合は、Hub の接続先 URL と認証トークンが保存済みである。
- 表示先の対応機器に必要なドライバーが設定され、メーカーのソフトが終了している。

## 共通の受け入れ条件
- TURZXとプレビューには、同じ描画から生成した内容を表示する。位置シフトと離席中のプレビュー保持は、[焼き付き防止ユースケース](../USBディスプレイの焼き付きを防ぐ/README.md)に従う。
- 取得した利用状況はメモリにだけ保持し、保存しない。
- 認証トークンは画面にもログにも出さない。
- 表示画像の見出しと項目名は英語とする。
- 表示レイアウトは保存したスタイルで決める。未設定時は`Gauges`を使う。表示先に不適合な場合は、[3.5インチ表示シナリオ](scenarios/3.5インチでサービスごとの利用枠を順番に表示する.md#表示先と向き)で定める機種の既定スタイルへ切り替えて保存する。適合しているスタイルは変更しない。
- 既存の`Gauges`と`Bars`は、大型表示の配置、契約の選択順、色、ページ構成を維持する。
- 9.2インチ用スタイルの巡回は[対象シナリオ](scenarios/表示しきれない利用枠を順番に切り替えて表示する.md)に従う。
- 3.5インチ標準スタイルの表示内容、ページ構成、常時巡回と専用の間隔設定は[対象シナリオ](scenarios/3.5インチでサービスごとの利用枠を順番に表示する.md)に従う。
- 表示先の切断は取得、プレビュー、巡回を止めない。再接続後は、その時点の最新表示を送る。
