# 利用状況をUSBディスプレイに表示する

## 主アクター
利用者

## 目的
選択した取得元（ローカルまたは Hub）の最新の利用状況を、TURZX とウィンドウのプレビューに常時表示し、作業中に横目で確認できるようにする。両機種にトークン数・推定コストと利用枠の残量を表示し、3.5インチではサービス別のトークン数・推定コストと利用枠から表示する内容を選び、順番に表示する。

## 前提
- 取得元が `Local` または `Hub` に決まっている。保存値がない場合は `Local` を使う。
- 取得元が `Hub` の場合は、Hub の接続先 URL と認証トークンが保存済みである。
- 表示先の対応機器が接続され、メーカーのソフトは終了している。9.2インチは WinUSB ドライバー設定済み、今回の3.5インチは Windows で USB シリアル機器として認識されている。

## 共通の受け入れ条件
- TURZX とプレビューには、本体が生成した同じ表示画像を表示する。
- 取得・受信した利用状況はメモリにだけ持ち、ファイルに保存しない。
- 認証トークンは画面にもログにも出さない。
- 表示画像の見出しと項目名は英語で表示する。
- 利用枠は、保存された表示スタイル `Display style`（`Gauges` または `Bars`）で描く。保存値がなければ `Gauges` とする。
- 9.2インチの配置・契約の選択順・色の規則は既存シナリオに従う。3.5インチの配置と巡回は「3.5インチでサービスごとの利用枠を順番に表示する」に従い、枠のグループ化・ラベル・色・残り時間の規則は既存と共通にする。
- `Usage Limits` で非表示にした枠と、取得元が `showMeter=false` として報告した枠は表示対象から除く。
