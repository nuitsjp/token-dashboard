# 3.5インチの画面更新方式を切り替える

- 種別: 拡張
- UI確認: 要

## 分岐条件

利用者がDisplay画面で3.5インチ用スタイルを選択している。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者がDisplay画面を開く | Rotate 180°の隣に`Blank on update`を表示する。未設定はOFFとする |
| 2 | 利用者がスイッチを切り替える | 即座に保存し、次の画像送信から選択した方式を使う |
| 3 | 利用者がアプリを再起動する | 保存した選択を復元する |

## 受け入れ条件

- OFFでは消灯せず、従来どおり全画面を順に書き換える。
- ONでは消灯中に差分を転送して点灯する。同一画像は再送しない。
- ONでも、初回、再接続、寸法変更、反転変更時は全画面を転送する。
- 切り替えても、表示中のページと巡回期限を維持する。
- 保存失敗時は元の選択に戻し、エラーを表示する。
- 9.2インチ用スタイルではスイッチを表示せず、9.2インチの動作は変更しない。
