# 表示する利用枠を選ぶ

- 種別: 拡張
- UI確認: 要

## 分岐条件
`Display` 画面で利用者が `Usage Limits` の契約または枠のチェックボックスを外す、または付ける。主成功の Usage Limits の描画の、母数となる契約と枠をこの系列で絞り込む。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が `Display` 画面を開く | 上から `Style`（`Display style` の選択とプレビュー）、`Usage Limits`、`Output` の区画を表示する。`Usage Limits` に、最新の利用状況でメーターを表示できる契約を、提供元・プラン名とともにチェックボックスで並べ、各契約の下に枠（名前と残量）を並べる。保存済みで表示しないと選んだ枠は外した状態、それ以外は付けた状態にする。契約は、枠がすべて付いていれば付き、すべて外れていれば外れ、混在なら中間表示にする |
| 2 | 利用者が枠のチェックボックスを外す | 直ちに保存し、その枠を除いた契約と枠から表示画像を生成し直して、TURZX とプレビューを同時に更新する。契約のチェック状態は、下の枠の状態に合わせて更新する |
| 3 | 利用者が契約のチェックボックスを外す | その下の枠をすべて外した状態にして直ちに保存し、表示画像を生成し直して更新する。契約のパネルと見出しは表示しない |
| 4 | 利用者が外した契約のチェックボックスを付ける | その下の枠をすべて付けた状態にして直ちに保存し、表示画像を生成し直して更新する |
| 5 | 取得元の利用状況が更新される、または1分が経過する | 選択を保ったまま、表示画像を生成し直す |
| 6 | 利用者がアプリを終了して再起動し、ウィンドウを開く | 保存済みの選択をチェックボックスに反映し、TURZX とプレビューも同じ選択で描く |

## 受け入れ条件
- 外した枠は、取得されていないものとして、主成功と `Bars` の規則（契約の並び順、円と行の組み立て、枠の個数の上限、収まらない契約の扱い）を適用する。契約の並び順に使う残量の最小値は、表示する枠だけで求める。`Gauges` と `Bars` の両方に同じ選択を適用し、Tokens は対象にしない。
- 枠は `provider`・`accountLabel`・`kind`・`label` の組で識別し、表示しないと選んだ枠だけを保存する。契約のチェック状態は保存せず、枠の状態から決める。保存値がない枠は表示する。
- 契約のチェックボックスの操作は、その契約の枠すべてを、1回の保存で付ける・外す。枠のチェックボックスの操作は、その枠だけを変え、ほかの枠の保存値を変えない。
- 一覧にない契約や枠の保存した選択は、取得元の切り替えや一時的な欠落で消さない。
- 選択は `Save` なしで直ちに反映し、同時に保存する。プレビューは操作のたびに更新する。保存に失敗した場合は、選択を保存前に戻し、エラーを表示し、表示画像も変えない。
- 選択の保存は、取得元・接続設定・表示先・表示スタイルの保存値と取得処理に影響しない。
- 表示する枠がない場合は、Tokens だけを表示する。
- 最初の利用状況を受信するまでは、一覧は空で、待機中であることを表示する。
