# 利用枠の表示スタイルをバーに切り替える

- 種別: 拡張
- UI確認: 要

## 分岐条件
`Display` 画面で利用者が利用枠の表示スタイル `Display style` を `Gauges` から `Bars` に変える。主成功の Usage Limits の描画から、円弧の代わりにこの系列へ分岐する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が `Display` 画面を開く | 上から `Style`（`Display style` の選択とプレビュー）、`Usage Limits` の区画を表示し、見出し `Display settings` と同じ段の右端に `Output` を表示する。`Display style` に保存済みの表示スタイルを選択状態で表示する。保存値がなければ `Gauges` を選択状態にし、プレビューは `Gauges` で描いた表示画像を表示する |
| 2 | 利用者が `Display style` で `Bars` を選ぶ | 選択した表示スタイルを直ちに保存し、`Bars` で描いた表示画像を生成し直して、TURZX とプレビューを同時に更新する |
| 3 | 取得元の利用状況が更新される、または1分が経過する | 表示スタイルを `Bars` のまま、表示画像を生成し直して更新する |
| 4 | 利用者がアプリを終了して再起動し、ウィンドウを開く | `Display style` に `Bars` を選択状態で表示し、TURZX とプレビューは `Bars` で描いた表示画像を表示する |

## 受け入れ条件
- `Display style` の選択肢は `Gauges` と `Bars` だけとする。`Gauges` を選ぶと、主成功の円弧の表示に戻る。
- 選択は `Save` なしで直ちに反映し、同時に保存する。保存に失敗した場合は、選択を保存前の値に戻し、エラーを表示し、表示画像も変えない。
- 表示スタイルの保存は、取得元・Hub の接続設定・表示先の保存値と取得処理に影響しない。
- 表示画像の左端の列に、Tokens の Today・Month・All を上から縦に並べる。期間ごとに、1行目の左に期間名、右に推定コスト（USD）を置き、2行目にトークン数（`12,345,678` のようにカンマ区切りで、略さない）を推定コストと右端をそろえて置く。トークン数が列の幅に収まらないときは文字を小さくする。
- Usage Limits の契約の選び方、並び順、見出し（提供元のアイコン、名前、プラン名）は、主成功と同じにする。契約のパネルは描かず、契約の見出しの下に枠のバーを置く。Tokens の列の右に置く。
- 契約ごとに、`showMeter` が真の枠を Hub が送った順に4つまで表示する。契約は、左の列から見て、追加しても枠が合計4つ以下かつ契約が2件以下になる最初の列の一番下に置き、置ける列がなければ右に新しい列を作る。列は4列までとし、5列目が必要になった契約は表示しない。
- 枠ごとに、枠の名前（`label`、空なら `kind`）、リセットまでの残り時間、残量の割合を1行に並べ、その下に列の幅いっぱいのバーを置く。枠の名前が入りきらないときは末尾を `…` で省略する。
- バーの色は、主成功の円弧と同じ規則（ペースの規則と残量の規則の悪い方）と同じ色（正常は紫 `#9085e9`、注意は黄 `#fab219`、危険は赤 `#f0616d`）で表示する。残量の割合がない枠は、バーの色を付けない。
- リセットまでの残り時間は、1日未満なら `2h 13m`、1日以上なら `3d 4h` の形式で表示し、同じ契約の行どうしで右端をそろえる。
