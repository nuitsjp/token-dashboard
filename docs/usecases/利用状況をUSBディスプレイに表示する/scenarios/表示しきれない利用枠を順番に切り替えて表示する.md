# 表示しきれない利用枠を順番に切り替えて表示する

- 種別: 拡張
- UI確認: 要

## 分岐条件
`Display` 画面で利用者が、右端にあるスイッチ `Cycle` を入れる。主成功の Usage Limits の描画で、表示領域に収まらず切り捨てていた契約を、この系列で順番に表示する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が `Display` 画面を開く | `Style` の区画で、`Display style` の選択と同じ高さの右端に、スイッチ `Cycle` とその右に切り替え時間 `Cycle time`(秒)を表示する。`Usage Limits` の契約のスイッチと同じデザインにする。保存済みの値を反映し、保存値がなければ `Cycle` は切、`Cycle time` は10秒にする |
| 2 | 利用者が `Cycle` を入れる | 直ちに保存し、表示画像を生成し直して TURZX とプレビューを同時に更新する。表示しきれない契約があれば、1ページ目から順番に切り替え始める |
| 3 | `Cycle time` の秒数が経過する | 次のページの表示画像を生成して更新する。最後のページの次は1ページ目に戻る |
| 4 | 取得元の利用状況が更新される | 現在のページ番号を保ったまま、最新の値で表示画像を生成し直す。ページ数が減って現在のページがなくなった場合は1ページ目に戻る |
| 5 | 利用者が `Cycle time` に秒数を入力して Enter を押すか、入力欄から離れる | 直ちに保存し、以後の切り替え間隔を入力した秒数にする。5〜3600の整数以外は保存せず、入力欄を保存済みの値に戻す |
| 6 | 利用者が `Cycle` を切る | 直ちに保存し、1ページ目(切り替えない場合と同じ表示)に戻す |
| 7 | 利用者がアプリを終了して再起動し、ウィンドウを開く | `Cycle` と `Cycle time` を保存した状態で表示し、1ページ目から切り替えを再開する |

## 受け入れ条件
- 切り替える単位はページとする。ページは、現在の `Display style` の規則(`Gauges` は7列の格子、`Bars` は4列・枠4つまで・契約2件までの列)で収まる契約の組を、契約の並び順に1ページ目から詰めたものとする。
- Tokens はどのページでも同じ位置に表示し、切り替えない。
- 全契約が1ページに収まる場合は、`Cycle` が入っていても切り替えず、1ページ目だけを表示する。
- `Cycle` が切の場合は、主成功と同じく1ページ目に収まる契約だけを表示する。
- 表示する契約と枠の選択(`Usage Limits` のチェックボックス)は、ページの組み立ての前に適用する。
- `Cycle time` は5〜3600の整数（秒）で、右寄せで表示する。保存値がなければ10秒とする。
- スイッチと `Cycle time` の操作は `Save` なしで直ちに反映し、同時に保存する。保存に失敗した場合は、保存前の値に戻し、エラーを表示し、表示画像も変えない。
- `Cycle` と `Cycle time` の保存は、取得元・接続設定・表示先・表示スタイル・枠の選択の保存値と取得処理に影響しない。
- TURZX とプレビューは、同じページを同じ時刻に表示する。
- 現在のページ番号は保存しない。
