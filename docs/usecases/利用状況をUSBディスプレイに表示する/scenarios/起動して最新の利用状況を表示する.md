# 起動して最新の利用状況を表示する

- 種別: 主成功
- UI確認: 要

## 開始条件
利用者が Windows にサインインし、アプリが起動する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が Windows にサインインする | アプリを起動してタスクトレイに常駐し、保存済みの接続設定で Hub の受信を始める。最初の snapshot を受信するまでは、利用状況の値を含まない `Waiting for Hub` の表示画像を TURZX に表示する |
| 2 | Hub が snapshot を送る | 受信した利用状況をメモリ上の最新状態にし、Tokens の Today・Month・All のトークン数と推定コスト、Usage Limits を描いた表示画像を生成して TURZX に表示する |
| 3 | 利用者がタスクトレイのアイコンをクリックする | ウィンドウを表示し、プレビューに TURZX と同じ最新の表示画像を表示する |
| 4 | Hub が利用量の変化を stats で送る | 最新状態を置き換えて表示画像を生成し直し、TURZX とプレビューの表示を同じ画像に更新する |
| 5 | 利用者がウィンドウの閉じるボタンを押す | ウィンドウを隠す。受信と TURZX の表示は続ける |
| 6 | 利用者がタスクトレイのメニューの `Exit` を押す | 受信を止め、TURZX に再起動を指示して起動直後の表示に戻し、アプリを終了する |

## 受け入れ条件
- 表示画像の上段に Tokens の Today・Month・All を横一列に並べ、期間ごとに期間名、トークン数（`12,345,678` のようにカンマ区切りで、略さない）、推定コスト（USD）をこの順に横に並べる。3つの期間は左端・中央・右端に置き、横幅に収まらないときは文字を小さくする。
- 下段の Usage Limits は、Hub が報告した契約（`providers` の各要素）ごとにまとめ、`showMeter` が真の枠を持つ契約だけを表示する。契約ごとに、提供元の名前（`provider`）とプラン名（`planLabel`、空なら `accountLabel`）を見出しにし、その下に `showMeter` が真の枠を1行ずつ、枠の名前（`label`、空なら `kind`）、リセットまでの残り時間、残量の割合とバーで表示する。1つの契約に表示する枠は4行までとする。
- 契約は Hub が送った順に5列へ並べる。枠が1つの契約は、先に置いた枠が1つの契約の下に、列の高さに収まる限り積む。列に収まらない契約は表示しない。
- 残量のバーは、50% 以上を緑、20% 以上を黄、20% 未満を赤で表示する。
- リセットまでの残り時間は、1日未満なら `2h 13m`、1日以上なら `3d 4h` の形式で表示し、同じ契約の行どうしで右端をそろえる。
- 受信がなくても、表示画像を1分ごとに生成し直し、残り時間を更新する。
- 最初の snapshot を受信するまでは、利用状況の値を表示しない。
- stats を受信したら、TURZX とプレビューの表示を同じ内容に更新する。
- TURZX へは、1920×462 の表示画像を時計回りに90度回転した Baseline JPEG（品質85）で送る。
- ウィンドウを隠している間も、TURZX の表示は更新し続ける。
- `Exit` で終了したあと、TURZX は起動直後の表示に戻っている。
