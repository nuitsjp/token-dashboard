# USBディスプレイの焼き付きを防ぐ

## 主アクター
利用者

## 目的
TURZX に同じ画像を長時間表示し続けても焼き付き・残像が出ないように、表示位置を少しずつずらし、席を離れている間は消灯する。

## 前提
- 「利用状況をUSBディスプレイに表示する」の主成功が動作しており、TURZX に表示画像が出ている。

## 共通の受け入れ条件
- 焼き付き対策のための状態（現在のずらし量、消灯中かどうか）は保存しない。
- 焼き付き対策は、取得元・接続設定・表示先・表示スタイル・枠の選択・Cycle の保存値と取得処理に影響しない。
- 焼き付き対策の対象は TURZX の出力だけとし、ウィンドウのプレビューは通常の表示画像のまま変えない。
