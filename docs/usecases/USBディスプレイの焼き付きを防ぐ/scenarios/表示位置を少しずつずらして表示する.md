# 表示位置を少しずつずらして表示する

- 種別: 主成功
- UI確認: 要

## 開始条件
TURZXに利用状況の表示画像が出ている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者がTURZXを見続ける | 3分ごとに機器用画像全体を、(0,0) → (4,0) → (4,4) → (0,4) → (-4,4) → (-4,0) → (-4,-4) → (0,-4)の順に移動して送り直す |
| 2 | 取得元の利用状況が更新される | 現在のずらし量と次の移動時刻を保ち、最新値で画像を生成して送る |
| 3 | 利用者がアプリを終了して再起動する | ずらし量を保存せず、(0,0)から巡回を再開する |

## 受け入れ条件
- 9.2インチと3.5インチを対象とし、3.5インチはGauges／Bars、横／縦、それぞれの180度反転に対応する。
- 正立画像の座標で画像全体を移動してから機器向けに回転・反転する。はみ出しを切り捨て、空いた部分を元画像の左上隅の色で埋める。
- ずらすのは機器用画像だけとし、プレビューは動かさない。
- ずらし量と3分間隔は固定とし、設定項目を設けない。
- Cycleとは独立して動き、データ更新・ページ切り替え・Style・反転・表示先の変更で、ずらし量と次の移動時刻をリセットしない。
- 更新がなくても3分ごとに送り直す。
- 離席中は進めず、復帰時に(0,0)へ戻す。復帰後の次の移動は3分後とする。
- 再接続時は、その時点のずらし量で最新画像を送る。離席中は黒画像を送る。
