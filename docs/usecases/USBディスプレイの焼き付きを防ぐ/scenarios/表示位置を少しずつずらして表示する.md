# 表示位置を少しずつずらして表示する

- 種別: 主成功
- UI確認: 要

## 開始条件
TURZX に利用状況の表示画像が出ている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が TURZX を見続ける | 3分ごとに、TURZX に送る表示画像全体の位置を次のずらし量へ移して送り直す。ずらし量は、横・縦とも -4〜+4 px の範囲で、次の8点を順に巡回する: (0,0) → (4,0) → (4,4) → (0,4) → (-4,4) → (-4,0) → (-4,-4) → (0,-4)。 |
| 2 | 取得元の利用状況が更新される | 現在のずらし量のまま、最新の値で表示画像を生成して送る。 |
| 3 | 利用者がアプリを終了して再起動する | ずらし量は保存せず、(0,0) から巡回を再開する。 |

## 受け入れ条件
- ずらしは、描画済みの画像全体の平行移動で行い、はみ出した部分は切り捨て、空いた部分は表示スタイルの背景色で埋める。
- ずらし量とその間隔（3分）は固定とし、設定を設けない。
- Cycle が入っている場合、ページの切り替え時刻とは独立にずらす。
- ずらしの間隔は、表示画像の更新の有無にかかわらず守る。更新がなくても3分ごとに送り直す。
