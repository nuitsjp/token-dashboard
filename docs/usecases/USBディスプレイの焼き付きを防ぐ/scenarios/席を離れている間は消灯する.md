# 席を離れている間は消灯する

- 種別: 拡張
- UI確認: 要

## 分岐条件
次の離席条件のいずれかが成立する。
- キーボード・マウスの無操作が `Away time`(分)に達した。
- Windows がモニターの電源を切った。
- PC がスリープまたは休止に入った。
- このセッションがロック、サインアウト、ユーザー切替、または手元のコンソールからの切断（リモートデスクトップ接続中を含む）で非アクティブになった。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が `Settings` 画面を開く | `Away` の区画に、離席と判定する無操作時間 `Away time`(分)を表示する。保存済みの値を反映し、保存値がなければ10分にする。 |
| 2 | 利用者が `Away time` に分数を入力して Enter を押すか、入力欄から離れる | 直ちに保存する。1〜240の整数以外は保存せず、入力欄を保存済みの値に戻す。 |
| 3 | 離席条件のいずれかが成立する | TURZX に黒一色の画像を送って消灯する。消灯中は、利用状況の更新・Cycle・ずらしによる再描画と送信を止める。ウィンドウのプレビューは変えない。 |
| 4 | 離席条件がすべて解除される（入力の再開、モニターの電源オン、スリープ・休止からの復帰、セッションの再開） | その時点の最新の利用状況から表示画像を生成して TURZX に送り、通常の表示に戻す。ずらし量は (0,0) から巡回を再開する。 |
| 5 | 消灯中に USB の抜き差しが起きる | 既存の規則どおり、つながった時点の最新表示を送る。ただし離席条件が成立している間は、通常の表示ではなく黒画像を送る。 |

## 受け入れ条件
- 無操作時間は、システム全体の最後の入力時刻から求める。ウィンドウ内の操作に限らない。
- 離席条件は論理和とし、解除は、すべての条件が解けたときだけ行う。
- `Away time` の操作は `Save` なしで直ちに反映し、同時に保存する。保存に失敗した場合は保存前の値に戻し、エラーを表示し、消灯の状態も変えない。
- `Away time` の保存は、他の保存値と取得処理に影響しない。
- 消灯の判定が失敗しても（通知の登録に失敗した場合など）、表示は通常のまま続け、アプリを止めない。
- 消灯中も、取得・受信は続ける。復帰時に最新値を表示できるようにする。
