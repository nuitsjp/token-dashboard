# 席を離れている間は消灯する

- 種別: 拡張
- UI確認: 要

## 分岐条件
TURZXに利用状況を表示している状態で、次の離席条件のいずれかが成立する。

- キーボード・マウスの無操作がAway timeに達した。
- Windowsがモニターの電源を切った。
- PCがスリープまたは休止に入った。
- このセッションがロック、サインアウト、ユーザー切替、またはコンソールからの切断で非アクティブになった。リモートデスクトップ接続中を含む。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者がSettings画面を開く | 両機種ともCycle・Cycle timeと同じ区画にAway timeを分単位で表示する。保存値がなければ10分とする |
| 2 | 利用者がAway timeを入力してEnterを押すか、入力欄から離れる | 直ちに保存する。1〜240の整数以外は保存せず、保存済みの値に戻す |
| 3 | 離席条件のいずれかが成立する | 選択中の表示先・Styleの寸法に合う黒画像を送る。通常画像の描画・送信と巡回を止め、プレビューは離席前の画像を保持する |
| 4 | 離席条件がすべて解除される | 最新値から通常画像を生成して送る。3.5インチでは離席前のページを巡回間隔1回分表示してから巡回する。ページがなくなった場合は既存のページ選択規則に従う。9.2インチの位置ずらしは（0,0）から再開する |
| 5 | 消灯中にUSBの抜き差しや表示先・Styleの変更が起きる | 適合する接続先へ、その寸法に合う黒画像を送る。不適合な組み合わせでは既存規則どおり送信しない。離席中は通常画像を送らない |

## 受け入れ条件
- Away timeは両機種共通の保存値とし、既存の範囲・既定値・保存形式を維持する。
- 無操作時間はシステム全体の最後の入力時刻から求める。
- 離席条件は論理和とし、すべて解除されたときだけ通常表示へ戻す。
- Away timeはSaveなしで保存する。保存失敗時は保存前の値に戻し、エラーを表示し、消灯状態を変更しない。
- Away timeの保存は、他の保存値を変更せず、取得処理を再起動しない。
- 消灯中も取得・受信を続け、復帰時に最新値を表示する。
- 3.5インチの黒画像は既存のRGB565送信経路を使う。横・縦Styleと、それぞれの180度反転に対応する。
- 描画中・送信待ちだった通常画像を、離席状態になった後に出力しない。
- 消灯状態・現在ページ・巡回期限は保存しない。再起動時は既存の起動規則に従う。
- 離席検知の失敗時は既存の障害時動作を維持し、アプリを止めない。
