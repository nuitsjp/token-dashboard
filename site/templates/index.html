Claude Code、Codex、Cursor、Antigravity などの利用枠の残量とリセットまでの時間を、TURZX 9.2 インチまたは対応する 3.5 インチ USB ディスプレイに表示し続けます。9.2 インチは一覧表示、3.5 インチはサービスごとの巡回表示で使えます。

Token Monitor と連携すると、40 種類以上の AI ツールの利用状況を表示できます。

残量を確かめるたびに、手が止まっていませんか

  • 実装の途中で 5 時間枠を使い切り、リセットまで待つことになる。
  • Claude Code、Codex、Cursor を併用していると、使用量を確かめる場所がツールの数だけある。
  • デスクトップのウィジェットはエディターの後ろに隠れ、全画面表示ではタスクバーも見えなくなる。

Token Dashboard を使えば、利用枠の状態を PC の画面の外に出しておけます。視線を少し下げるだけで、どの枠がいつリセットされるかが分かります。

このままだと足りなくなる枠は、色が変わる

色は、残量と減り方の速さの両方から決まります。たとえば 5 時間枠が始まって 30 分で 40% を使っていたら、残量が 60% あっても黄色になります。

残量で見る
40% 以下で黄色、25% 未満で赤になります。
減り方で見る
時間どおりに使った場合の残量と比べて、8 割を下回ると黄色、5 割を下回ると赤になります。

2 つの判定のうち、悪い方の色で表示します。

5 時間枠での色の例

  • 5h2h 30m

    紫

    余裕がある

    残量 70%、リセットまで 2 時間 30 分。時間どおりなら 50% です。

  • 5h4h 30m

    黄色

    減り方が速い

    残量 60%、リセットまで 4 時間 30 分。時間どおりなら 90% です。

  • 5h1h 0m

    黄色

    残量が 40% 以下

    残量 35%、リセットまで 1 時間。

  • 5h4h 0m

    赤

    減り方がとても速い

    残量 35%、リセットまで 4 時間。時間どおりなら 80% です。

  • 5h30m

    赤

    残量が 25% 未満

    残量 15%、リセットまで 30 分。

残量が同じ 35% でも、リセットまで 4 時間ある場合は減り方が速すぎるため赤になります。

残りが少ないサービスから順に、左から並ぶ

ゲージはサービスごとにまとまり、いちばん残りが少ない枠を持つサービスが左端に来ます。ゲージは横に最大 7 つ並びます。5 時間枠と週の枠があるサービスは、外側の円が 5 時間枠、内側の円が週の枠です。円の下には、それぞれのリセットまでの残り時間が出ます。

上の段には、今日・今月・累計のトークン数と推定コスト（USD）を表示します。

表示するサービスと枠は、Display 画面でプレビューを見ながら選べます。円形の Gauges と横棒の Bars も、ここで切り替えます。

エディターを全画面にしても、隠れない

TURZX は、Windows からはモニターとして認識されません。マウスポインターとウィンドウは、これまでどおりメインのモニターの中だけを動きます。

アプリは、値が変わったときと 1 分ごとに画像を作り、USB で送ります。毎秒 58 回描き直して送り続ける試験でも、CPU 使用率は PC 全体の約 0.9% でした（作者の PC で計測）。

インストールして USB につなげば、表示が始まります

  1. インストーラーを実行する

    {{INSTALLER_NAME}} を実行します。インストーラーにコード署名をしていないため、初回は Windows SmartScreen の画面が出ます。「詳細情報」を押してから「実行」を選んでください。インストール後はタスクトレイに常駐し、Windows へのサインイン時に自動で起動します。

  2. TURZX を USB でつなぐ

    付属の USB Type-C ケーブルで PC につなぎます。TURZX のメーカー製ソフトを起動している場合は、先に終了してください。Display 画面の右上にある Output にデバイス名（例: TURZX1.0 (xxxx)）が出ていれば、認識できています。

  3. 表示を確かめる

    最初は、この PC のログを読む Local モードで表示します。この PC で Claude Code や Codex を使っていれば、設定しなくても利用状況が出ます。

この PC だけなら Local、複数の PC をまとめるなら Hub

取得元は、ウィンドウ左の Connection 画面で切り替えます。

Hub モードの設定手順

  1. Token Monitor の設定画面で、「マルチデバイス同期」の「このデバイスで Hub をホスト」を選びます。表示される接続先 URL（例: http://192.168.0.17:17321）と共有シークレットを控えます。

  2. Token Dashboard の Connection 画面で Data source を Hub にし、Hub URL と Access token（共有シークレット）を入力して Save を押します。

よくある質問

無料で使えますか

はい。MIT ライセンスで公開しているオープンソースです。ソースコードは GitHub にあります。

利用状況のデータはどこに保存されますか

Token Dashboard は、受け取った利用状況をメモリ上だけで持ち、履歴を残しません。Local モードでは、同梱の tokscale がログ解析用のキャッシュをアプリ専用のフォルダーに置きます。Hub の URL とアクセストークンは Windows の DPAPI でユーザーごとに暗号化して保存し、アクセストークンは画面にもログにも表示しません。

インストール時に警告が出ました

インストーラーにコード署名をしていないため、初回は Windows SmartScreen の画面が出ます。「詳細情報」を押してから「実行」を選ぶと、インストールが始まります。

新しいバージョンにはどう更新しますか

アプリは起動するたびに、GitHub Releases の新版をバックグラウンドで確認します。見つかった新版は、Ed25519 の署名とインストーラーのハッシュを検証してから取得しておきます。ウィンドウ上部の通知に出る「Update and restart」を押すと、更新して再起動します。

Windows 10 や Mac で使えますか

使えません。対応しているのは Windows 11 (x64) だけです。

ほかのサイズの TURZX でも使えますか

9.2 インチ（1920 × 462）と、USB 1A86:5722・識別文字列 USB35INCHIPSV2 の 3.5 インチ USB シリアル機種に対応しています。画面サイズだけでは互換性を判断できません。

3.5 インチでは何を表示できますか

サービスごとに利用枠と Tokens の両方・利用枠のみ・Tokens のみを選び、表示の ON/OFF も切り替えられます。Tokens はサービス全体の今日・今月・累計のトークン数と推定コストです。横・縦とそれぞれの上下逆、5〜300 秒の巡回間隔に対応します。Display の Service content を開いて設定してください。

Token Monitor は必要ですか

Local モードで使うなら不要です。複数の PC の利用量をまとめたいときや、Cursor と Antigravity の利用枠を表示したいときに、Token Monitor と連携する Hub モードを使います。

TURZX のメーカー製ソフトと一緒に使えますか

同時には使えません。Token Dashboard で表示する間は、メーカー製のソフトを終了してください。Token Dashboard を終了すると、TURZX は起動直後の表示に戻ります。

TURZX を自分のプログラムから動かしたい人へ

Token Dashboard が使っている USB 通信の仕様を公開しています。暗号化した 512 バイトのヘッダーの組み立て方と、Go の実装例を載せています。
